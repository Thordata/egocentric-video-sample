# Egocentric Video Sample

Public sample and metadata for first-person video data workflows.

This repository is dedicated to the [First-Person Multi-Scene Video Collection](https://datamall.thordata.com/datasets/VID-20260713-172340-516) available through Thordata DataMall.

## Dataset

The collection provides first-person HD video covering scenes such as:

- Handicrafts
- Shopping
- Strolling
- Hand-object interaction
- Daily activity understanding

## Repository Scope

This repository is intended to provide a limited, reviewed sample of the associated video data together with its metadata and documentation.

The complete commercial dataset is not included in this repository.

Approved sample media is added only through a reviewed release process. The repository does not include unrelated datasets or video products.

## Intended Use

The sample is intended to support:

- Video understanding
- Computer vision
- Multimodal AI
- Vision-language model prototyping
- Embodied AI and robotics research
- Video retrieval workflows
- Dataset structure and metadata evaluation
