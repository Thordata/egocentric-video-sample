# Egocentric Video Sample

Public sample and metadata for first-person video data workflows.

This repository is associated with the [First-Person Multi-Scene Video Collection](https://datamall.thordata.com/datasets/VID-20260713-172340-516) available through Thordata DataMall.

## Dataset

The collection contains first-person HD video covering scenes such as:

- Handicrafts
- Shopping
- Strolling
- Hand-object interaction
- Daily activity understanding

## Repository Scope

This repository contains a limited sample of the associated video data and its metadata.

The sample is intended for:

- Video understanding
- Computer vision
- Multimodal AI
- Vision-language model prototyping
- Embodied AI and robotics research
- Video retrieval workflows

The sample is not the complete commercial dataset.
